# ADR（Architecture Decision Record）

このプロジェクトにおける、後から経緯を追いにくい技術的決定を記録する場所。
「なぜそうしたか」が実装やコミットログだけでは追いにくいもの（フレームワーク移行、
インフラ構成の変更、後方互換を切る決定など）を対象とする。日々のリファクタや
軽微な修正は対象外（それらはコミットメッセージ・PRで十分）。

## 書き方

- ファイル名: `NNNN-短い題名.md`（`NNNN` は4桁の連番、既存の最大値+1）
- フォーマットは以下を踏襲する:

```markdown
# NNNN. タイトル

- ステータス: 提案中 / 承認済み / 廃止（後継: NNNN）
- 日付: YYYY-MM-DD

## コンテキスト

なぜこの決定が必要になったか。

## 決定

何を決めたか。

## 影響

この決定によって何が変わるか（メリット・トレードオフ・今後の制約）。
```

- 決定を覆す場合は既存ファイルを書き換えず、新しいADRを追加して「ステータス」に
  旧ADRの廃止を明記し、旧ADR側にも後継ADRへのリンクを追記する。
